# ML Party 🎲🤖

Game papan 3D untuk belajar **Machine Learning** sambil bermain, terinspirasi Pummel Party — full Bahasa Indonesia, gratis, langsung main dari browser.

## Fitur

- 🗺️ **5 map 3D**: Pulau Data, Kota Sirkuit, Puncak Awan, Stasiun Antariksa, Kedalaman Data (bawah laut, Petak Arus & Kraken Data) — bercabang, ada jalan pintas & petak Gravitasi
- 🏆 **Mode Turnamen** (bracket gugur 8 peserta, Piala + lencana "Juara Turnamen"), **Tantangan Teman** via Kode Tantangan salin-tempel, **Kotak Misteri Harian** + tonggak streak, **Robot Pendamping**, minigame Arena **Susun Pipeline**, **Kartu Profil PNG** unduhan, warna robot bebas + 3 topi baru
- 📚 **24 materi ML** yang mudah dipahami + Ensiklopedia kartu koleksi & simulasi interaktif (regresi, decision tree, neural network)
- 👥 **2–4 pemain**: offline 1 perangkat + bot, atau **online beda perangkat** dengan room berkode 6 karakter & Room Master
- 🎲 Gameplay ala Pummel Party: dadu 0–9, sistem HP, 5 item sabotase, petak Reaper/Bank/Trofi/Jackpot/Toko/Duel, Penjaga Kota, Raid Boss kooperatif
- ⚡ Tantangan Bersama berebut bel, Balap Teka-Teki, Duel 1v1, Tantangan Kode ala Codewars, Mode Kelas untuk guru
- 🏆 XP & Level (Pemula Data → Grandmaster ML), lencana, misi, profil & skin robot tersimpan, sertifikat kemenangan bisa diunduh
- 🎓 Mode Karier solo, Mode Latihan Soal dengan rapor per topik, Tantangan Harian
- 🌿 Tempo santai: timer bisa dilonggarkan atau dimatikan

## Cara Main Online

1. Satu pemain memilih **Buat Room Online** → menjadi Room Master dan mendapat kode room
2. Bagikan kode (atau tautan undangan) ke teman
3. Teman membuka game ini, memilih **Gabung Room**, memasukkan kode
4. Room Master mengatur map, kesulitan soal, dan target — lalu mulai permainan

## Menjalankan

Cukup buka `index.html` di browser, atau aktifkan GitHub Pages:

1. Buka **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / **(root)** → **Save**
4. Tunggu ±1 menit, game live di `https://hafidcuy.github.io/ML-3D/`

Satu file HTML mandiri; multiplayer memakai WebRTC (PeerJS) dari CDN — tanpa server sendiri.
